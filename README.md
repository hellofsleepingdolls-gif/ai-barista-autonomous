# Autonomous AI Barista Infrastructure ☕🤖

An autonomous B2B automation system designed to streamline coffee shop operations, handle customer inquiries, and sync data directly with CRM systems.

## 🛠️ Tech Stack
*   **Orchestration:** n8n (Self-hosted)
*   **AI Layer:** OpenAI API / Prompt Chaining
*   **Database & CRM:** Supabase (PostgreSQL) / Integration-ready
*   **Frontend Deployment:** Netlify

## 🚀 Key Features
*   **Automated Response System:** Processes incoming customer orders and requests with 90%+ intent accuracy.
*   **CRM Integration:** Instantly maps customer data and creates leads/tasks for the team.
*   **Zero-Overhead Scaling:** Bypasses third-party no-code platform limitations using a self-hosted architecture.
